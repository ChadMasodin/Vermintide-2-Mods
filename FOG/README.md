Makes The Feast of Grimnir and A Quiet Drink available in the mission menu.


Important Note
It is recommended to disable the "A Quiet Drink" mod to ensure everything displays correctly.


How to Start on official realm
Step 1: What you need

Be sure you have installed the "Vermintide Mod Framework"
Ignore Step 2 if you know what the order should look like

Step 2: Mods Order

Open the Vermintide 2 Launcher and Check the mods order
1. Vermintide Mod Framework
2. The Feast of Grimnir

Step 3: Glitch start

Start the game in Modded Realm first.
In game, choose the map under "Own Game" and start it once.
You don't need to play the whole map, just close the game

Final Step: Lets play

Now you only need to start your game in the official realm and under "own game" you should still find the map.
